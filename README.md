# voice_changer — 人声 → 童声 / 女童声 / 老人音（MATLAB）

把一段录音变声：**人声 → 童声**、**人声 → 女童声**、**任意人声 → 老人音**，保持时长不变。

预设名描述的是**变成什么音色**，任何输入都能配任何预设——见第三节。

纯 base MATLAB 实现，**不需要任何工具箱**（Signal / Audio / DSP 授权均为 0 也能跑）。

```matlab
voice_changer('voice.wav', '--preset', 'child', 'out_child.wav')   % 一行搞定
```

---

# 一、快速开始

```matlab
% 命令行
matlab -batch "voice_changer('voice.wav', '--preset', 'child', 'out_child.wav')"

% 图形界面
start "" matlab -r "voice_changer_app"
```

`voice_changer` 也是函数，可以在Matlab中调用，只要结果不存储文件：

```matlab
[y, info] = voice_changer('voice.wav', '--preset', 'elder');   % y 是输出波形
y = voice_changer(x, fs, '--preset', 'child');                 % 数组进，必须给采样率
```

**数组输入必须显式给采样率**（`voice_changer(x, fs, ...)` 或 `--fs`）。漏掉会按 16 kHz 处理，
44.1 kHz 的录音会全频偏 2.76 倍。

# 二、命令行

## 2.1 位置参数

```matlab
voice_changer('in.wav', '--preset', 'child', 'out.wav')            % 第一个是输入，第二个是输出
voice_changer('in.wav', '--preset', 'child')                       % 只算不落盘
voice_changer('in.wav', '--preset', 'child', '--out', 'out.wav')   % 或用 --out
```

## 2.2 选项一览

| 选项 | 作用 |
|---|---|
| `--preset <名>` | 预设（见第三节） |
| `--pitch <半音>` | 相对变调，如 `--pitch 7` |
| `--target <Hz>` | 绝对目标基频（**高音输入要真抬高必须用它**，见 3.3） |
| `--ratio <r>` | 直接给倍率 |
| `--ref <Hz>` / `--ref auto` | 基频参考；`auto` 表示用实测输入基频 |
| `--formant <r>` | 共振峰倍率，覆盖预设 |
| `--tilt <dB/oct>` | 频谱倾斜（正 = 更亮） |
| `--tremor <pct>` `--rate <Hz>` `--breath <pct>` | 老人音颤音 / 气声 |
| `--nfft <n>` `--hop <n>` | STFT 参数 |
| `--max-f0 <Hz>` `--ratio-max <r>` `--allow-down` | 上限与方向守卫（见 3.2） |
| `--no-phase-lock` | 关闭相位锁定（默认**开启**，见 6.1） |
| `--no-normalize` | 不做电平匹配，保留变调后的原始电平 |
| `--fs <Hz>` | 输入按此采样率解释 |
| `--plot` `--quiet` `--help` | 频谱图 / 静默 / 帮助 |

## 2.3 退出码

`0` 成功；非零表示失败，错误信息在 stderr。批处理脚本可直接用来判断。

# 三、预设

| preset | 目标音色 | 基频 | 共振峰 | 倾斜 | 颤音 | 气声 |
|---|---|---|---|---|---|---|
| `child` | **童声**（男孩感，默认） | 目标 210 Hz | ×1.15 | +0.50 dB/oct | – | – |
| `child_bright` | 童声，更高更亮 | 目标 235 Hz | ×1.22 | +1.00 dB/oct | – | – |
| `child_female` | **女童声**（音高更高） | 目标 250 Hz | ×1.18 | +0.50 dB/oct | – | – |
| `elder` | 老人音 | ×0.866 | ×0.94 | −0.25 dB/oct | 1.0 % @5 Hz | 0.9 % |
| `elder_female` | 老人音（音高更高） | ×0.901 | ×0.96 | −0.25 dB/oct | 0.8 % | 0.7 % |
| `normal` | 原声（恒等对照） | ×1.000 | ×1.000 | 0 | 0 | 0 |

别名：`kid` / `child_male` / `child_soft` → `child`；`girl` → `child_female`；
`old` / `old_man` → `elder`。

**预设名描述的是"变成什么"，不是"输入是什么"。** 任何输入都能配任何预设：
`child` 得到男孩感的童声，`child_female` 得到女孩感的童声（音高更高、略亮）。
选哪个取决于**想要哪种童声**，与录音本人的性别无关。

## 3.1 音高与共振峰必须一起动

儿童与成年男性的**声道长度比约 1.14–1.25**，而**基频比约 1.5–2.0**。所以正确做法是
**共振峰放大得比音高少**：`child` 是音高 ×1.40（对 150 Hz 输入）配共振峰 ×1.15。

把共振峰调到与音高一样大（×1.40）就变成卡通尖声。反过来说，**想让声音"不那么尖"，
必须把 `--target` 与 `--formant` 一起降**——只降音高会让声道听起来比音高暗示的更小，反而更尖。

## 3.2 三道约束

预设里每个倍率都受三件事约束，报告会明确标出是否被限制：

1. **比例上限**：`ratiomax = 目标 / 100 Hz 地板` → `child` 2.100、`child_bright` 2.350、
   `child_female` 2.500。三个预设共用同一个 100 Hz 地板，这是它们在低音区保持顺序的前提。
2. **输出上限** `max_f0`：仅在固定参考（`--ref <数值>`）下生效。`--ref auto` 时输出已等于目标，
   上限只会把预设拉离自己的目标，因此自动失效。
3. **方向守卫**：**童声预设不把基频往下压**。若目标是 210 Hz 而输入已是 240 Hz，
   倍率会被钉在 ×1.000（只改音色、不改音高），报告标注 `[direction limited]`；
   `--allow-down` 可解除。

## 3.3 高音输入（女声、童声）的已知局限

`child` 的目标 210 Hz **低于**典型女声（240 Hz 左右），方向守卫会把它钉在 ×1.000；
`child_bright`(235) 与 `child_female`(250) 也只比 240 高一点。**要让这类高音输入真正抬高
（250–300 Hz），必须显式给 `--target`**：

```matlab
voice_changer('female.wav', '--preset', 'child', '--target', 300, 'out.wav')
```

这是"绝对目标 + 方向守卫"这套设计的必然结果，不是 bug。**注意这与预设的选择是两件事**：
预设决定"变成什么音色"，`--target` 决定"抬到多高"。

# 五、支持的音频格式

由扩展名决定；读靠 `audioread`、写靠 `audiowrite`。下表为**实测**结果（R2024b / Windows）：

| 用途 | 扩展名 |
|---|---|
| 输出 | `.wav` `.flac` `.mp3` `.m4a` `.mp4` `.ogg` `.oga` `.opus` |
| 输入 | 同一套（**`.mp4` 的音轨也能当输入**） |
| 不支持 | `.aiff` `.aif` `.au` `.w64` `.caf` `.webm` `.mkv` `.avi` `.mov` |

* **`.m4a` / `.mp4` 只接受 44.1 或 48 kHz**（AAC 编码器限制），16 kHz 结果会报
  `SampleRate 值不受支持`。要存 AAC 就先 `--fs 44100`。
* **有损格式会挪动测量读数**：同一个 1.100 s 信号经 MP3 往返变成 1.155 s（编码器延迟）。
  要测量请用 `.wav` / `.flac`。
* 输出名不带扩展名时自动补 `.wav`（唯一一处替你决定格式的地方）。
* 多声道输入取平均降为单声道。

# 六、算法链

```
输入 ──① 谱分析──┬─ 倒谱滤波求谱包络（12 ms lifter）
                 └─ YIN 差分函数求基频 / 浊音比例 / 谱质心
   ──② 基频变换──  相位声码器时间拉伸 r（含 identity phase locking）
                    + 带限重采样压缩 r  →  音高 ×r、时长不变
   ──③ 共振峰变换─  log 频率轴上对谱包络做分段线性 warp
                    + 频谱倾斜 + 低频抑制（整段一次 FFT，零相位增益）
   ──④ 老人音附加─  时变分数延迟颤音 + 包络调制气声
   ──⑤ 输出──────  电平匹配到输入 RMS、0.9 以上软削顶、报告
```

| 阶段 | 文件 |
|---|---|
| STFT / ISTFT | `vc_stft.m`, `vc_istft.m` |
| 谱包络 / 掩模 | `vc_env.m`, `vc_mask.m` |
| 变调 | `vc_pitchshift_pv.m`, `vc_resample.m` |
| 分析 | `vc_analyze.m` |
| 老人音层 | `vc_tremor.m`, `vc_breath.m`, `vc_localenv.m` |

## 6.1 相位锁定（默认开启）

相位声码器让每个 bin 各自推进相位，于是**同一帧内各分音之间的相位关系**不再被带到下一帧
（丢失"垂直相干性"）——听感上就是**金属感、涂抹、像加了轻微混响**。注意这**不是丢了谐波**：
实测浊音帧谐波占比只从 −0.24 dB 掉到 −1.44 dB，**分音都还在，只是每帧都在游走**。

解法是 Laroche & Dolson（ICMC-1997 式 8）的 identity phase locking：一个区内的 bin
共享谱峰的**相位旋转**，各自保留自己的分析相位，

```
angle_Y(m,k) = angle_Y(m,p) + angle_X(m,k) − angle_X(m,p)
```

区域以幅度谱的局部极大（论文的 4 邻居判据）为峰、按 Voronoi 划分；峰自身的相位用普通
相位声码器递推跟踪自己的频率，递推输入是**分析相位**。

**判断依据是听感。** 真实录音上做 A/B（电平已对齐）试听，**开启锁定明显减轻金属感**。
而物理指标**没有一个能复现这个结论**——这点值得记住，因为光看数会得出相反的结论：

| 指标 | 结果 |
|---|---|
| 帧速率伪影谱线 | 受控信号上改善 47/46/46/13 dB；真实语音上只是**换了个位置** |
| HNR（谐波窗内能量占比） | 换窗口后两版基本相同（±60 Hz 窗下差 0.23 dB）；窄窗下看似变差是窗口太窄造成的假象 |
| 谱质心 / 高频占比 | 变化很小（纯幅度统计） |
| 帧速率包络调制 | 锁定版反而高 20 dB（测的是幅度调制，不是相位） |
| **每分音相位游走** | 受控元音上**降低 2.3×**（中位 sd 8.78 → 3.85 Hz）；真实语音上被信号自身音高运动淹没 |

`--no-phase-lock` 关闭，回到每 bin 独立递推。自检会断言锁定**确实在降低相位游走**，
以防它静默退化成空操作。

```matlab
demo_voice_changer      % 全部断言，约 1–2 分钟，通过则打印 ALL CHECKS PASSED
app_check               % 界面结构与算式自检，约 20 s
```

`demo_voice_changer` 用**两个独立测量**作基准（不看实现自己的读数），覆盖：

| 检查 | 实测值 |
|---|---|
| 三个童声预设的上限 = 目标/地板，实际倍率 = min(请求, 上限) | 上限 2.100 / 2.350 / 2.500；实际 1.750 / 1.958 / 2.083 |

| 变调器精度 | 500 Hz / 1 kHz 误差 ≤0.4 % |
| 重采样器 | 200 Hz 纯音 ×0.866…×2.0 误差 **0.0000 %** |
| 共振峰阶段 | F1/F2/F3 在 `--formant 0.85/1.00/1.30` 下按比例移动 |
| 抗混叠 | 6.5 kHz 纯音经 ×1.400 后残留 **−18.4 dB**（阈值 −14 dB） |
| 电平规则 | 输入 RMS 0.1429 → 输出 0.1429（**×1.000**） |
| 相位锁定 | 每分音游走 5.58 → 3.69 Hz（**1.51×**） |
| 恒等路径 | `normal` 预设峰值残差 **−Inf dB**（逐位透明） |
| 时间轴 | 内容跨度与输入一致（变调不改变时长） |

**时间轴检查是独立的一项，不能由"长度相同"替代**：变调模块的"拉伸"与"重采样"方向若配反，
输出样本数依然精确正确，但音频会被加速数倍。所以自检用静音中的脉冲标记核对**内容跨度**。

# 八、已知限制

1. **基频读数在变声后的音频上不可靠。** 转换后的信号里有一根帧速率伪影（分级隔离：
   STFT/ISTFT 往返 −90 dB、重采样器 −90…−125 dB、**变调级 −28…−48 dB**），跟踪器会锁到它。
   因此报告不自由搜索：输出改用**以"本次转换应有的基频"为中心、±6 % 宽**的窄带重新分析，
   并如实写成 `narrow-band estimate, +-6 %`；窄带内找不到周期时给出设计值并注明未经独立验证。
   实测：合成 120 Hz 元音转 `child`，自由搜索得 349.6 Hz（偏 66 %），窄带得 **209.5 Hz**（目标 210）。

2. **大幅倍率精度下降**：`--pitch 12`（×2.0）时相位声码器偏差约 0.1–4 %；更小的 hop 不会改善。

3. **瞬态涂抹**：爆破音、咔哒声会被相位声码器抹开。这属于相位声码器的固有特性，与金属感
   （相位锁定已解决，见 6.1）无关；要根治需改用基音同步算法（TD-PSOLA 一类），
   本项目尚未实装。难点在基音标记检测——低通峰值作锚点会跳周期（1500 个周期只出 583 个标记），
   逐周期相关匹配又容易被阈值与搜索窗边界截断（只剩 60–150 个标记）；标记错的症状是
   **咬字消失**，比金属感严重。重做时第一道验收标准应当是"标记数 = 周期数 ±10 %"，
   且必须在**带音高起伏**的信号上测（纯稳态音即使标记多出 6.8 倍也照样通过）。

4. **老人音的颤音/气声是合成效果**，用于听感上的"衰老感"，不是生理建模。

5. **共振峰因子默认固定**，不做"按音高缩放"（`--formant-track` 为实验开关）。
   原因是可复现性：缩放判定把原始倍率与设计点比较，而真实录音几乎贴在阈值上，
   同一命令两次运行可能给出不同结果，换来的差别却听不出来。

6. **采样率**：44.1/48 kHz 长文件处理时间是 16 kHz 的约 3 倍，建议先降采样。

7. **相位锁定的频率精度**：受控元音上锁定版分音最大偏离 `k·f0·ratio` 达 39 Hz，
   未锁定在 8 Hz 以内。试听未听出走音，需要精确音高时以 `info` 里的倍率为准。

# 九、性能

实测（默认 `child` 预设、**相位锁定开启**、R2024b）：

| 素材 | 总耗时 | 折算 |
|---|---|---|
| 2 s @ 16 kHz | **0.46 s** | 230 ms / 音频秒 |
| 60 s @ 44.1 kHz | **1.51 s** | 25 ms / 音频秒 |
| 139 s @ 44.1 kHz | **8.83 s** | 64 ms / 音频秒 |

**折算值相差 3.6 倍不代表非线性**：短素材被固定开销主导（函数编译、一次性 FFT 规划），
长素材才反映边际成本。判断"多久能跑完"看总耗时列。

同一段 139 s 音频关掉相位锁定是 **7.14 s**，即**锁定约贵 1.4×**（成本在 `vc_pitchshift_pv`
内的逐帧相位分区循环）。即便如此仍比实时快十几倍。

成本主要在 `vc_resample` 与 `vc_istft` 的重叠相加，随样本数线性增长；44.1 kHz 做同样的事
约为 16 kHz 的三倍。长文件想更快就先降采样到 16 kHz 再处理——转换效果与输入采样率无关。

* **MATLAB R2024b**（R2020b 以上应可，未逐一验证）
* **不需要任何工具箱**：Signal / Audio / DSP 授权均为 0 时可完整运行
* 图形界面需要 `backgroundPool` 做后台转换；不可用时自动退化为同步 + 进度条
