# voice_changer — 正常人声 ⇄ 儿童音 ⇄ 老人音（MATLAB 命令行实现）

用 MATLAB 实现的变声器：把一段说话录音转换成**儿童音**或**老人音**，也可以输出接近原声的"成人音"做 A/B 对比。
核心逻辑全部在命令行脚本里完成（谱分析、尺度变换、滤波），每个环节都有可复现的测量结果作验证。

---

# 一、外部命令行调用（推荐入口）

外部调用统一走 **`run_voice_changer`**（`run_voice_changer.m`）。它把参数整理好再交给 `voice_changer`，并设置**退出码**（0 成功 / 1 失败），方便在 `.bat`、shell、Python `subprocess` 里判断成败。

## 1.1 基本形式

```bat
matlab -batch "run_voice_changer('PRESET','IN.WAV','OUT.WAV' [OPTIONS])"
```

Windows 上建议先切到项目目录（脚本会自己 `addpath`，但从别处调用时用绝对路径最稳）：

```bat
cd /d C:\Users\daeda\Documents\Programming\voice_changer
matlab -batch "run_voice_changer('child','我的录音.wav','童声.wav')"
matlab -batch "run_voice_changer('elder','我的录音.wav','老人音.wav')"
```

PowerShell 里注意引号嵌套，推荐用**单引号包外层、双引号包内层**：

```powershell
matlab -batch 'run_voice_changer("child","我的录音.wav","童声.wav")'
```

## 1.2 三种位置参数写法

```bat
:: 完整：预设 + 输入 + 输出
matlab -batch "run_voice_changer('child','in.wav','out.wav')"

:: 省略预设：第 1 个位置参数若是音频文件，就当作输入（预设默认 child）
matlab -batch "run_voice_changer('in.wav','out.wav')"

:: 省略输出：不写就用 out_<preset>.wav
matlab -batch "run_voice_changer('elder','in.wav')"

:: 或用 --out 显式指定输出（适合和选项混排）
matlab -batch "run_voice_changer('elder','in.wav','--out','out.wav','--tremor',1.5)"
```

判定规则很简单：**第一个位置参数若是已知预设名就当作预设，否则当作输入文件**。所以文件名不要和预设重名。

## 1.3 传选项

`run_voice_changer` 会把所有 `--xxx` 选项**原样透传**给 `voice_changer`，所以完整选项集都能用：

```bat
:: 女声做童声，明确指定目标音高与共振峰，并输出频谱对比图
matlab -batch "run_voice_changer('child_female','女声.wav','kid.wav','--target',300,'--formant',1.15,'--tilt',1,'--plot')"

:: 老人音，加强颤音和气声
matlab -batch "run_voice_changer('elder','男声.wav','old.wav','--tremor',1.8,'--rate',4.5,'--breath',1.2)"

:: 不用预设，完全手调：升 7 个半音 + 共振峰 1.25 + 1% 气声
matlab -batch "run_voice_changer('in.wav','out.wav','--pitch',7,'--formant',1.25,'--breath',1)"

:: 静默批处理（不打印报告）
matlab -batch "run_voice_changer('child','in.wav','out.wav','--quiet')"
```

## 1.4 辅助命令

```bat
matlab -batch "run_voice_changer --help"        :: 使用说明
matlab -batch "run_voice_changer --selftest"    :: 跑自检，通过返回 0
matlab -batch "demo_voice_changer"              :: 自检 + 基准测试（更详细）
```

## 1.5 退出码与脚本化

| 情况 | 退出码 |
|---|---|
| 转换成功 | **0** |
| 输入文件不存在 | **1**（并打印明确原因） |
| 预设名拼错 | **1**（提示"既不是预设也不是音频文件"，并列出可用预设） |
| 输出路径不可写 | **1** |
| 自检失败 | **1** |

因此可以这样在批处理里用：

```bat
@echo off
for %%F in (rec\*.wav) do (
    matlab -batch "run_voice_changer('child','%%F','out\%%~nF_child.wav','--quiet')"
    if errorlevel 1 echo FAILED: %%F
)
```

Python 调用示例：

```python
import subprocess, sys
cmd = ['matlab', '-batch',
       "run_voice_changer('child','rec.wav','kid.wav')"]
p = subprocess.run(cmd, capture_output=True, text=True)
if p.returncode != 0:
    print('failed:', p.stdout, p.stderr)
```

## 1.6 性能预期（重要）

| 项目 | 实测（本机 R2024b） |
|---|---|
| **MATLAB 进程启动** | **约 12.4 s**（每次 shell 调用都要付，与音频无关） |
| 脚本内部：2 s 音频 | 0.09–0.35 s |
| 脚本内部：30 s 音频 @16 kHz | 0.6 s |
| 脚本内部：60 s 音频 @16 kHz | **1.1 s** |
| 脚本内部：60 s 音频 @44.1 kHz | **3.1 s** |

**结论与建议：**

* **单次 shell 调用的墙钟时间约 13–15 s，其中 12.4 s 是 MATLAB 解释器启动**，不是算法慢。
  这是 `matlab -batch` 的固有开销，与"脚本运行 < 1 s"的目标不冲突——脚本本身远低于 1 s。
* **要批量处理多个文件，就在一个 MATLAB 会话里循环调用**，别反复起进程：

  ```matlab
  addpath('C:\Users\daeda\Documents\Programming\voice_changer')
  files = dir('rec\*.wav');
  for k = 1:numel(files)
      voice_changer(fullfile('rec', files(k).name), '--preset', 'child', ...
                    fullfile('out', ['kid_' files(k).name]), '--quiet');
  end
  ```
* **44.1 kHz 的长录音建议先降采样到 16 kHz**，处理时间约快 3 倍（60 s 文件：3.1 s → 1.1 s），
  语音带宽对变声足够：

  ```matlab
  [x, fs] = audioread('录音.wav'); x = mean(x, 2);
  audiowrite('录音16k.wav', vc_resample(x, fs/16000, round(numel(x)*16000/fs)), 16000);
  ```
* 需要**免启动开销**的外部调用时，两条路：MATLAB Engine for Python（进程常驻），
  或 MATLAB Compiler 编译成独立 exe（需要该工具箱授权）。目前仓库没有做这两件事。

# 二、在 MATLAB 里调用

```matlab
cd C:\Users\daeda\Documents\Programming\voice_changer
addpath(pwd)

% 文件进、文件出
[y, info] = voice_changer('voice.wav', '--preset', 'child', 'out_child.wav');

% 只算不落盘
y = voice_changer('voice.wav', '--preset', 'elder');

% 数组进（必须显式给采样率，见下方说明）
[x, fs] = audioread('voice.wav');
y = voice_changer(x, fs, '--preset', 'child');      % 位置参数形式
y = voice_changer(x, '--fs', fs, '--preset', 'child');   % 或选项形式
```

**数组输入的采样率必须显式给出。** 传给 `voice_changer` 的数组不自带采样率，
漏掉会被当成 16 kHz——44.1 kHz 的录音当成 16 kHz 处理，所有频率会偏 2.76 倍，音高全错。
（用**文件路径**时不需要，`audioread` 会自己返回采样率。）

`info` 结构体包含：实际倍率、检测到的 F0、各级耗时、输出文件名、各阶段参数。

# 三、预设

| preset | 基频 | 共振峰 | 倾斜 | 颤音 | 气声 | 适用 |
|---|---|---|---|---|---|---|
| `child` | 目标 210 Hz（按 `--ref`，默认 150 Hz） | ×1.15（固定） | +0.50 dB/oct | – | – | **男声**→儿童音（**默认**） |
| `child_bright` | 目标 235 Hz | ×1.22（固定） | +1.00 dB/oct | – | – | 同上但更高、声道变化更大；原 `child` |
| `child_soft` | 同 `child` | 同 `child` | 同 `child` | – | – | `child` 的别名，向后兼容 |
| `child_female` | 目标 250 Hz（`--ref` 190） | ×1.18（固定） | +0.50 dB/oct | – | – | **女声**→儿童音（这是唯一会向上推女声的儿童音预设） |
| `elder` | ×0.866 | ×0.94 | −0.25 dB/oct | 1.0 % @5 Hz | 0.9 % | 老人音（男） |
| `elder_female` | ×0.901 | ×0.96 | −0.25 dB/oct | 0.8 % | 0.7 % | 老人音（女），更柔和 |
| `normal` | ×1.000 | ×1.000 | 0 | 0 | 0 | 恒等，A/B 对比（**逐位透明**） |

> **上限规则（修订：修掉了一个把预设顺序颠倒的 bug）**
>
> `--ref auto`（儿童音预设的默认）下，请求倍率是 `目标 / 实测基频`，所以
> **输出基频就等于目标**；只有检测失败、退回固定参考（`reffallback`）时，倍率才等于
> `目标 / 参考`。于是两道上限的职责必须分开：
>
> * **倍率上限 `ratiomax` = 目标 / 地板**，地板 = 该预设愿意处理的最低输入基频。
>   三个儿童音预设共用 **地板 100 Hz**：`child` 2.100、`child_bright` 2.350、
>   `child_female` 2.500。**地板必须和目标同序**：早先按"设计参考"分别取 110/120/150，
>   结果 130 Hz 男声上 `child_female` 被自身上限压到 217 Hz，仍低于 `child_bright`
>   的 235 Hz —— 同一个颠倒只是从区间中部搬到了底部。
> * **输出上限 `maxf0`（320/340 Hz）在 `--ref auto` 下被禁用**。它的用途是挡住"固定参考 +
>   高输入"的失控（150 Hz 参考下 250 Hz 女声会被推到 391 Hz）；`auto` 下没有这种失控，
>   上限只会把预设拉离它自己的目标。实测：148.5 Hz 男声上 `child` 被 320 Hz 截到 207.9 Hz、
>   `child_female` 被 340 Hz 截到 195.5 Hz —— **目标高的那个反而更低**。
>   `--max-f0` 仍显式生效，`--ref <数值>` 时预设上限照旧生效。
>
> * **方向闸门：儿童音预设绝不降低基频。** `--ref auto` 下倍率是 `目标/实测`，这个式子
>   没有方向概念——而三个绝对目标（210/235/250 Hz）与**成年女声区间重叠**，所以女声输入
>   必然触发反向转换。实测 60 s 女声（240.5 Hz）跑 `child`：倍率 ×0.873、输出 **183.5 Hz**、
>   声道 ×1.15 —— 预设精确命中了自己的目标，却做出了一个**更粗的成年人**，而报告里看不出
>   任何异常。现在 `auto` 参考下倍率下限被钉在 1（儿童基频不可能比成人低），
>   报告里会写明 `[direction limited: ...]`；`--allow-down` 解除限制，`--ratio/--pitch/--target`
>   是显式指令、不受影响，`--ref <数值>` 时也不生效（调用者已经声明了倍率所依据的假设）。
>
> 修正前后（148.5 Hz 男声录音）：`child` 207.9 → **210 Hz**，`child_female` 195.5 →
> **250 Hz**，`child_bright` 232.7 → **235 Hz**。女声录音上 `child` 由 183.5 → **243.5 Hz**
> （×1.000，只改声道），`child_female` 由 250.2 → **250 Hz**（×1.042，不受影响）。
>
> 代价只有一个，已实测：倍率变大后共振峰掩模要补得更深（`child` 1.15/1.414 = **0.813**，
> 原来是 1.15/1.400 = 0.821），所以 `child` 的能量谱质心从 1100 Hz 升到 1125 Hz
> （相对干声 1.498 → 1.531，**+2.3 %**，听感上很小）。`child_female` 的变化大得多
> （919 → **1466 Hz**），也就是说它现在**明显比 `child` 尖** —— 这正是修正的目的：
> 修正前它在男声上比 `child` 更闷，那才是颠倒的。

> **默认儿童音是 210 Hz / ×1.15 这一组**（原先作为 `child_soft` 备选）。选它的原因：
> 共振峰掩模要补的深度从 `1.22/1.567 = 0.779` 变成 `1.15/1.400 = 0.821`，**谱整形更浅**，
> 实测掩模对这一级几乎不再改变亮度（合成元音上 −1.3 %，旧的 235 Hz 版本是 +36 %），
> 主观上"更柔、更不刺耳"。**音高与共振峰必须成对选**——只降 `--target` 会让声道听起来比
> 音高暗示的更小，反而更尖，理由见 §6 第 7 条与 `voice_changer.m` 的 FORMANTS 段。
>
> **共振峰因子默认是"固定值"**：`child` 永远是 ×1.15、`child_female` 永远是 ×1.18，
> 不随 `--ref`/自动参考算出的音高倍率变动（`--formant-track` 才开启按音高缩放，
> 属实验选项，默认关闭）。
>
> **`child` / `child_bright` / `child_female` 预设内置 `--nfft 1024 --hop 256`**（其余预设
> 仍是 512/128）。这是唯一一个实测能减轻相位声码器"金属感"的参数：真实录音、倍率 1.567 下
> 浊音帧谐波占比从 −1.44 dB 改善到 −0.96 dB（约多 10 % 的帧能量留在谐波里而不是抹到谐波之间），
> 谱质心 1128 → 1112 Hz，峰值因子 14.5 → 12.5。老人音预设保持 512/128：实测换长窗反而更差。

选项（优先级高于预设）：
`--pitch <半音>` `--target <Hz>` `--ratio <r>` `--ref <Hz>` `--formant <r>` `--formant-track` `--tilt <dB/oct>`
`--tremor <pct>` `--rate <Hz>` `--breath <pct>` `--fs <Hz>` `--nfft <n>` `--hop <n>`
`--max-f0 <Hz>` `--ratio-max <r>` `--allow-down`
`--target-level <dBFS>` `--no-normalize` `--plot` `--quiet` `--help`

你的录音是**女声（F0 ≈ 250 Hz）**时：`child` 在 `--ref auto` 下请求 `210/250 = ×0.84`，
但**方向闸门**会把它钉回 ×1.000 —— 输入已经是成人女声、比儿童目标还高，此时 `child`
能诚实提供的只有"声道 ×1.15"，报告里会标 `[direction limited]`（想要真的降下来听效果，
加 `--allow-down`）。想往儿童方向走要用 `child_female`（目标 250 Hz，实测 ×1.04，几乎不动
音高、只缩声道），或显式控制：`--target 300 --formant 1.18`。

# 四、算法链

| 步骤 | 处理内容 | 文件 |
|---|---|---|
| ① 谱分析 | 倒谱滤波提取谱包络；YIN 差分函数估计基频、浊音比例、谱质心 | `vc_env.m`, `vc_analyze.m` |
| ② 基频尺度变换 | 相位声码器**时间拉伸 r** + 带限重采样**压缩 r**，两者时长抵消 → 音高 ×r、时长不变 | `vc_pitchshift_pv.m`, `vc_resample.m` |
| ③ 共振峰变换 | log 频率轴上对谱包络做分段线性 warp，并联立频谱倾斜与低频抑制；整段一次 FFT 施加零相位增益 | `vc_mask.m` |
| ④ 老人音附加层 | 时变分数延迟颤音 + 包络调制的高通气声 | `vc_tremor.m`, `vc_breath.m`, `vc_localenv.m` |
| ⑤ 输出 | RMS 归一化到 −18 dBFS、削顶保护、报告、可选 `--plot` | `voice_changer.m` |

两个必须算清的换算（都写在代码注释里）：

* 变调把**所有**频率（含共振峰）乘 `r`，所以共振峰 warp 实际施加 `formant_ratio / r`；
* 最终共振峰位置 = 原位置 × `formant_ratio`（700 Hz 在 `child` 下 ≈854 Hz，`elder` 下 ≈658 Hz）。

# 五、正确性验证（`demo_voice_changer` 全部 PASS）

自检输入是**已知基频/共振峰的稳态合成元音**；音高与共振峰用**互相独立**的谱峰跟踪测量
（搜索带由声明倍率决定，从而固定被跟踪峰的"身份"，否则"找最强峰"会让别的谐波冒充）。

| preset | 音高声明 | 实测 | 共振峰声明 | 实测 |
|---|---|---|---|---|
| normal | ×1.000 | ×1.000 | ×1.000 | ×1.000 |
| child | ×1.750 | **×1.759** | ×1.150（固定） | ×1.209 |
| child_bright | ×1.958 | **×1.912** | ×1.220（固定） | ×1.297 |
| child_female | ×2.083 | **×2.086** | ×1.180（固定） | ×1.108 |
| elder | ×0.866 | **×0.867** | ×0.940 | ×0.867 |
| elder_female | ×0.901 | ×0.871 | ×0.960 | ×1.031 |
| `--pitch 12` | ×2.000 | **×1.998** | ×1.300（`--formant`） | ×1.300 |

另外验证：输出长度不变、无 NaN、无削顶、`normal` 恒等路径峰值残差 −∞ dB、
`--target` 命中所要求比值、10 s 文件在预算内。

**固定共振峰默认值检查**：`child` 在 120 Hz 输入（远低于设计点 150 Hz，正是"按音高缩放"
会生效的区间）下必须给出 ×1.150 且 `formant_tracked = false`；`--formant-track` 必须给出
更高的 ×1.300 且音频与默认**不同**；`--no-formant-track` 必须与默认输出**逐位相同**。
这样"默认是固定值"这件事一旦被改回去，自检立刻失败。

**儿童音预设的"成对 + 上限 + 方向 + 顺序"检查**：`child`(210/150, ×1.15)、`child_bright`(235/150, ×1.22)、
`child_female`(250/190, ×1.18) 三组都必须同时满足五件事：
①倍率 = `min(请求倍率, 目标/地板)`；②`ratio_max` 必须**正好**等于 目标/地板
（旧的自检断言的是"倍率 = 目标/参考"，而那个值当时**就是**上限本身，所以一个"上限让预设
在低音上永远够不到目标"的 bug 能完整通过自检）；③共振峰倍率**小于**音高倍率 —— 这是真正的
物理约束（儿童声道长度比 1.14–1.25 < 基频比 1.5–2.0）；
④**在 130 Hz 的男声区间里三个预设的输出必须随目标递增**（210 < 235 < 250 Hz）—— 上限写成
设计倍率时顺序会变成 `child 1.400 > child_bright 1.567 > child_female 1.316`，也就是
"目标最低的那个最尖"；⑤**在 240 Hz 的女声区间里三个预设的输出都不允许低于输入**
（顺序只要求非递减：`child` 与 `child_bright` 都被闸门钉在 ×1.000，两者相等是正确行为），
并且 `--allow-down` 必须还原原始倍率、同时清掉"方向已限制"标记。

**时间轴检查**（用静音中的脉冲标记，见下）：child 内容 0.59–0.82 s、elder 0.59–0.83 s，输入 0.60–0.82 s。
**真实录音检查**：目录里存在非生成的 wav 时，自动取 20 s 跑 `child`/`elder`，核对长度与内容跨度。

> 长度相同**不代表**速度相同——变调模块曾经把"拉伸"和"重采样"方向配反，输出样本数依然精确正确，
> 但音频被加速了 2.4 倍、尾部是静音。所以自检里必须有独立的时间轴检查，这一项就是为此加的。

模块级精度：

* 重采样器（`vc_resample`）：200 Hz 纯音 ×0.866…×2.0 → 输出频率**误差 0.0000 %、幅度 1.0000**；
* 变调器：500 Hz / 1 kHz 音误差 ≤0.4 %，200 Hz ≤3 %（该处谐波落在 FFT 频点之间）；
* 基频估计（YIN）：85/100/120/150/165/210 Hz 稳态信号**误差 0.0 %**、浊音比例 1.00。

# 六、已知限制

1. **高音区八度误差**：YIN 对 >210 Hz 的稳态音可能锁到半周期（260 Hz 读成 130 Hz）。
   因此 `child` 用 `--ref`（默认 150 Hz）作绝对锚点，不依赖自动检测；
   报告中的输出 F0 在测量不可靠时显示 `F0 readout unreliable`，而不是给出错误数字
   （转换本身仍是正确的，时长与倍率已由客观检查确认）。
2. **大幅倍率精度下降**：`--pitch 12`（×2.0）时相位声码器实测偏差约 0.1–4 %；
   更小的 hop 不会改善（会引入相位绕卷混叠，已实测）。
3. 相位声码器对**瞬态**（爆破音、咔哒声）有涂抹，长文件听感上有轻微"金属感"，是该类算法的固有特性。
   实测该缺陷不是"丢了谐波"而是"谐波游走"：浊音帧谐波占比只从 −0.24 dB 掉到 −1.44 dB（512/128），
   但波形残差已达 −0.7 dB（对齐后与输入相减）。**能改善的部分已经做完**：抗混叠重采样（见下）、
   儿童音预设改用 1024/256 长窗。**剩下的必须换成基音同步算法（TD-PSOLA 一类）才能根治**，
   见 §8。
4. 老人音的颤音/气声是**合成**效果，用于听感上的"衰老感"，不是生理建模。
5. **采样率**：44.1/48 kHz 长文件处理时间是 16 kHz 的约 3 倍，建议先降采样（见 1.6）。
6. 清音/白噪段不参与共振峰变换（包络增益在无声段被掩蔽），因此不会把噪声放大成金属声。
7. **共振峰因子默认固定，不做"按音高缩放"**（`--formant-track` 为实验开关，默认关）。
   原因不是精度而是**可复现性**：开启缩放时，判定条件是把**原始音高倍率**与预设设计点
   `r0 = 235/150 = 1.5667` 比较，而真实录音几乎贴在这个阈值上——一段 138 s 男声
   （检测 F0 148.2 Hz，原始倍率 1.5856，仅高出 1.2 %）按 4 s 窗口算出的倍率在
   1.068–1.785 之间波动，5 个窗口里有 2 个越过阈值，于是因子在 1.22 与 1.30 上限之间
   跳变（F1 854 / 910 Hz），同一条命令两次运行可能给出不同结果。
   而它换来的差别只有 1.220 → 1.235（1.2 %）、各频带能量 0.26–0.43 dB，
   相对于相位声码器本身的音色改变完全听不出来。所以默认取固定值：
   **没有需要判定的分支，就没有会翻转的结果**；`--formant` 永远可以显式覆盖。
8. **重采样器抗混叠（已修）**：`vc_resample` 的截止频率原本是 `min(1, ratio)`，而
   `ratio > 1` 恰好就是它**抽取**（每 `ratio` 个输入样本取一个）的方向——也就是
   `vc_pitchshift_pv` 最后那一步 `vc_resample(ys, ratio, n)`，所有变高音都要走这一步。
   抽取时不做低通等于没有抗混叠，于是输出奈奎斯特（`fs/2/ratio`）以上的内容全部折回
   3–5 kHz，正好压在 F3/F4 上，听起来是"粗、金属边"而不是"高频空气感"。
   现在截止频率取 `1/ratio`，并让滤波器长度随抽取倍数增长（抽得越狠过渡带越要窄）。
   实测：6 kHz 纯音经倍率 1.567（输出奈奎斯特 5105 Hz），输出 RMS 相对输入从 **−0.2 dB
   降到 −21.0 dB**；`demo_voice_changer` 已把这条固定成回归检查（阈值 −14 dB）。
   本次实测的 138 s 男声里，5.1 kHz 以上占 −16.2 dB，这一部分原来是被整段折回来的。

# 七、男声→童声"太尖细 / 机械感"的实测结论

用 `测试2.wav`（138.8 s @ 44.1 kHz，检测 F0 148.9 Hz）逐项测过，结论分三层：

**① "尖细"里有一部分是 bug，已经修掉**：抗混叠（上面第 8 条）。它折回的正是 5.1–8 kHz 的
齿音与高共振峰，听觉上就是"呲呲的金属边"。

**② 音高与共振峰的搭配本身是对的，不建议只调其中一项**：

| 量 | 数值（当前默认 `child`） | 说明 |
|---|---|---|
| F0 | 148.9 → 210 Hz（×1.400） | 儿童（约 5–8 岁）实测 F0 通常 250–300 Hz |
| 共振峰 | ×1.15（×1.40 变调后由掩模补回 ×0.821） | 儿童声道约短 20–25 % |
| 能量谱质心 | 733 → ~1250 Hz | 变亮是必然的——变调把**所有**频率一起乘倍率 |

关键点：儿童与成年男性的声道长度比（约 1.14–1.25）**小于**基频比（约 1.5–2.0），
所以正确做法是共振峰放大**少于**音高。当前 ×1.15 / 音高 ×1.40 落在真实儿童区间内；
把共振峰调到跟音高一样大（×1.40）才会变成卡通尖声。因此**想让"音调不那么高"必须把
`--target` 与 `--formant` 一起降**——只降音高会让声道听起来比音高暗示的更小，反而更尖。
默认预设（210 Hz + ×1.15）就是按这条做的：相对旧的 235 Hz + ×1.22 版本，
掩模要补的深度由 `0.779` 变成 `0.821`（谱整形更浅），实测掩模级亮度变化由 +36 % 降到 −1.3 %。

**③ "机械感"的根因是相位声码器本身**：

* 浊音帧谐波占比：输入 −0.24 dB → 变调后 −1.44 dB（512/128），**1024/256 可回到 −0.96 dB**；
* 对齐后与输入相减的波形残差已达 **−0.7 dB**（残差与信号同量级），说明缺陷是**相位**而非幅度；
* 纯音变调本身是准的（500 Hz/1 kHz ≤0.4 %），所以不是"跑调"，而是**谐波在帧间游走**，
  听感即金属/机器人味。

已做完的缓解：抗混叠 + 儿童音预设改 1024/256 长窗 + 默认改用更柔的 210 Hz 预设。
**根治需要换基音同步算法（TD-PSOLA）**，但**本项目试过并回退了**：难点不在合成而在
**基音标记检测**——用低通峰值作锚点会跳周期（1500 个周期只出 583 个标记），改用逐周期
相关匹配后又被阈值和搜索窗边界反复截断链（只剩 60–150 个标记）。标记错的症状是
**咬字消失**（比"机械感"严重得多），所以这条实验支路已整体删除，当前只保留相位声码器。
若将来重做，第一道验收标准应当是"标记数 = 周期数 ±10 %"，并且必须在**带音高起伏**的
信号上测（纯稳态音即使标记多出 6.8 倍也照样通过）。

**试听对照**（`make_ab.m` 生成，16 kHz，同一段 24 s）：

| 文件 | 内容 |
|---|---|
| `AB_00_A_dry.wav` | 输入（A/B 参考） |
| `AB_01_B_child.wav` | 默认 `child`（F0 210 Hz，共振峰 ×1.15） |
| `AB_02_C_child_bright.wav` | `child_bright`（F0 235 Hz，共振峰 ×1.22）——旧默认，用来对比"更柔"是否成立 |
| `AB_03_D_child_light.wav` | `child` + `--formant 1.10`（只降共振峰） |
| `AB_04_E_pv_only.wav` | 只做变调（不加共振峰/倾斜）——用来判断"金属感"来自哪一级 |
| `AB_05_F_child_prev.wav` | `child` **带上限修正前**的倍率（`--ratio-max 1.400`） |
| `AB_06_G_cf_prev.wav` | `child_female` 修正前的倍率（`--ratio-max 1.316`） |
| `AB_07_H_cf_new.wav` | `child_female` 现在实际输出（目标 250 Hz） |

`AB_05` / `AB_06` 是上限修正的直接对照：旧上限下 `child` 得 252 Hz、`child_female` 得
195 Hz（**目标高的反而更低**），现在分别是 248 / 303 Hz（这里的 Hz 是自检里跟踪器的读数，
不是组合梳测得的基频；两者的差别见 §6 第 1 条）。修正后 `child_female` 明显比 `child`
更尖，这正是预设顺序应有的样子。
